# Image Finder & Generator Skill

This skill helps users find or create suitable images for essays, posters, presentations, reports, websites, and social media.

## What It Does

1. Takes a short image description from the user.
2. Searches the web for existing images.
3. Provides image sources, authors, and licence information.
4. Recommends the most suitable image.
5. If no suitable image is found, creates an AI image prompt or generates a new image.
6. Clearly labels AI-generated images.

## Best For

- Academic posters
- Presentation visuals
- Essay illustrations
- Social media graphics
- Conceptual images
- Food security, climate, water, sustainability, and social justice topics

## Important Rule

Search first.  
Generate only when existing images are unsuitable or unavailable.

## Copyright Principle

Never use an image without checking the source and licence.
